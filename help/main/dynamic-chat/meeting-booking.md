# Geben Sie Personen die Möglichkeit, mit Ihrem Verkaufsteam Meetings zu buchen

Verwenden Sie Dynamic Chat, um Leads schneller mit dem Vertrieb [!DNL target] verbinden. Geben Sie Besuchern die Möglichkeit, Meetings mit verschiedenen Vertriebsmitarbeitern zu buchen, indem Sie Ihre Vertriebsmitarbeiter als Benutzer über [Admin Console](https://adminconsole.adobe.com/) hinzufügen. Jeder Agent sollte seinen eigenen Kalender verbinden.
